# BubiFM77AV40EX

FUJITSU FM77AV40EX のエミュレーターです。
[Common Source Code Project](https://takeda-toshiya.my.coocan.jp/common/index.html) の eFM77AV40EX エミュレーションコアを利用しています。



> [!WARNING]
>
> 開発中です。macOSでは動作するかも。



## 対応環境

| OS | 最低バージョン | CPU |
|---|---|---|
| macOS | 13.5 | Intel / Apple Silicon |


## 入手方法

GitHub Releases で配布します。

## ROM について

ROM ファイルは同梱していません。実機から吸い出した ROM を利用者が用意し、アプリケーションから ROM フォルダーを指定してください。

## 言語

日本語と英語の UI に対応しています。
